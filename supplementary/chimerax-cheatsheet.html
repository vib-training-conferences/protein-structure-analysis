Remember

  • Every menu click is echoed in the Log as a command. Click once, then copy the command and reuse it.
  • Hydrogen bonds depend on the tool and its cut-offs. Report them with the definition. Run hbonds before and after addh and compare.
  • Use help hbonds (any command name) for the manual page; usage hbonds for the short syntax.
  • Undo a display mess: hide atoms; cartoon; view · reset colours: color bychain · start again: close; open 3p0g.
